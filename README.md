Verde Bay — a complete open-world crime game (three.js): explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police (1–5 star wanted level with chases and a helicopter), 7 story missions, 3 weapons, a HUD with a minimap, radio stations and safehouse saves. All city, characters, story, art and sound are original.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
